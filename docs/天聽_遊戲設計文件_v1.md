## 0. 摘要與核心循環

### 0.1 一句話
- 新君即位的第一天，國庫將空、權閹在側、皇叔在外、流寇已起、建州坐大。你要在 5 年（180 旬）內讀奏摺、下詔書、任免大臣、調兵遣將，讓王朝中興，至少不要亡在你手上。

### 0.2 三大玩法支柱
| 支柱 | 玩家做什麼 | 主要成本 | 對應章節 |
|---|---|---|---|
| 奏摺（被動） | 讀大臣送來的報告，硃批准駁 | 細讀耗精力；不讀只能看票擬摘要 | §5 |
| 詔書（主動） | 主動下令：徵兵、調兵、任免、外交、密偵、內廷 | 精力＋錢糧＋執行時間＋送達延遲 | §6 |
| 大戰略 | 輿圖上的勢力、部隊、戰爭；聽報後決定要不要干預前線 | 干預會遲到；不干預就由大臣依自己的傾向處理 | §10、§11 |
| 人事（貫穿三者） | 誰在什麼位子、授權多大，決定了你看到什麼、事情怎麼被處理 | 每個人有能力、傾向、派系、私心 | §7、§8 |

### 0.3 設計原則
- **資訊即權力**：所有數字都是「據報」，附來源與日期。唯一絕對可靠的是自己人掌握的東廠，但查得越多越容易曝光
- **時間即距離**：詔書要送達、要執行；越遠的地方，你知道的越是舊消息
- **授權即取捨**：管得多就累死；放手就讓大臣的傾向與私心決定結果
- **每個選擇都要有代價**：沒有絕對最佳解；兩難選項至少同時傷到兩方
- **運氣可以準備，但不能預測**：賭性選項一律顯示五級勝算，不顯示數字
- **局末揭露真相**：史書把「你以為的歷史」和「真實的歷史」並排對照

### 0.4 核心循環（每旬）
```
退朝過場（新到奏報、戰報、事件）
   ↓
① 處理彈出事件（兩難／賭性選擇）
   ↓
② 奏摺匣：看票擬 → 決定細讀哪幾份（精力）→ 硃批
   ↓
③ 輿圖：看各地據報兵力、勢力、戰況 → 選擇干預
   ↓
④ 詔書列：擬旨 → 看到精力、錢糧、執行時間、勝算 → 用璽
   ↓
⑤ 內廷：消遣（每旬一種）、後宮、召見
   ↓
退朝 → 模擬推進一旬（§3.3）
```

### 0.5 和 MVP 相比的主要變化
| 項目 | MVP v0.4 | v1 |
|---|---|---|

## 2. 劇本與開局

### 2.1 背景
- **時代**：架空王朝，仿明末。年號「崇寧」，開局為崇寧元年正月上旬
- **處境**：先帝在位二十餘年、怠政多年，駕崩前寵信司禮監；太子（玩家）倉促即位，十九歲
- **為何架空**：避免玩家依歷史知識預判誰會反。人名、地名的格局仿明，但人物都是程序生成的，只有身分固定

## 3. 時間與回合流程

### 3.1 時間單位
- 1 回合 = 1 旬（約 10 天）；1 個月 3 旬；1 年 36 旬
- 一局最多 180 旬（崇寧元年正月上旬到五年十二月下旬）
- 驛程以「日」記，換算成旬數時無條件進位：`旬數 = ceil(日數 / 10)`
- 季節影響：秋季（7–9 月）北方遊牧勢力活躍；夏季（5–7 月）汛期；冬季（11–1 月）行軍時間 +1 旬（北方）

### 3.2 玩家階段（不限時，不推進時間）
1. 退朝過場：日期、本旬新到奏摺數、急報數、完成的詔書
2. 事件彈窗：依序呈現（急報 → 兩難事件 → 戰報動畫 → 內廷 → 完工通知），可以「前往細讀」、「下一則」、「全部略過」
3. 自由操作：奏摺、輿圖、詔書、人事、內廷、外交，順序自由
4. 退朝：確認後推進

### 3.3 模擬結算順序（每旬）
- 沿用 MVP `src/core/tick.ts` 的骨架，新增 ★ 的步驟：

| 順序 | 步驟 | 內容 |
|---|---|---|
| 1 | 詔書送達 | 在途的詔書抵達，開始執行；執行完畢的詔書生效 |
| 2 | ★ 人事交接 | 新官到任、離任官員回京 |
| 3 | ★ 大臣自行處分 | 有授權的大臣處理職掌內的事（§7.5），產生處分錄 |
| 4 | 事件鏈演化 | 各鏈推進階段、產生線索文書（原疑案模組） |
| 5 | ★ 勢力 AI | 各勢力決定擴張、掠邊、通商、結盟（§10.3） |
| 6 | 軍事 | 部隊移動 → 交戰判定 → 方略 → 結算 → 陷落與收復 |
| 7 | 經濟 | 錢糧入庫、支出、太倉消耗、欠餉 |
| 8 | 民心與民變 | 各地民心漂移；民變、教門 |
| 9 | ★ 派系 | 聲勢、怨望更新；彈劾潮、專權、政變判定 |
| 10 | 內廷 | 心情、勞損、疾病、後宮、子嗣、刺殺判定 |
| 11 | 奏報生成 | 依授權與重要度，決定哪些上呈（§5.1）；其餘進處分錄 |
| 12 | ★ 狀態倒數 | 狀態剩餘旬數 −1，到期移除 |
| 13 | 結局判定 | §16 |
| 14 | 精力回復 | §4.1 |

### 3.4 存檔
- 每次退朝自動存檔；另有 3 個手動存檔位
- 「鐵血模式」（可選）：只有一個自動存檔，不能讀舊檔
- 決定論：同一種子加上同一串操作，結果必定相同（§19.3）

## 4. 皇帝本人

### 4.1 精力與勞損
| 參數 | 數值 |
|---|---|
| 精力上限 | 10（勤政 11） |
| 每旬回復 | +4（勤政 +5） |
| 龍顏 ≥ 75 | 回復 +1 |
| 龍顏 < 25 | 回復 −1 |
| 患病 | 回復 −1／−2／−3（輕／重／危） |
| 本旬花費 ≤ 1 | 下旬額外 +2（休養） |
| 透支下限 | −3：精力可以降到負數 |
| 透支的代價 | 退朝時精力每低於 0 一點，勞損 +1 |
| 操勞 | 一旬花費 ≥ 7，勞損 +1 |
| 勞損範圍 | 0–10；每旬自然 −0.5（不透支、花費 ≤ 4 時） |
| 罷朝靜養 | 詔書：本旬不再下旨、不能細讀，勞損 −3；奏摺全部依票擬處理 |

- **精力消耗一覽**

| 行為 | 精力 |
|---|---|
| 看票擬摘要、硃批 | 0 |
| 細讀全文 | 1 |
| 小詔（任免、徵兵、犒軍、密查……） | 1 |
| 大詔（出征、宣戰、議和、抄家、廢立……） | 2 |
| 大計（南遷、親征） | 3 |
| 召見 | 2（同旬召見第二人以後 1） |
| 消遣 | 0–2（見 §4.5） |
| 設定授權 | 0（每旬最多改 3 個職位） |

- **介面**：頂欄是 10 顆燭火，透支的部分以紅色殘燭表示；勞損是燭台下的蠟淚，分 5 級

### 4.2 健康與疾病
- **每旬生病機率**：`2% + 勞損 × 3% + (龍顏 < 25 ? 5% : 0) + (京師疫癘 ? 8% : 0) + (服丹中 ? 4% : 0)`
- **病情三級**：輕（風寒、頭風）、重（瘧疾、痢疾）、危
  - 每旬有機率好轉或惡化；勞損 ≥ 6 時惡化機率加倍
  - 危症每旬 15% 駕崩
- **療法**（詔書，內廷類）

| 療法 | 效果 | 風險 |
|---|---|---|
| 太醫院會診 | 好轉機率 +20% | 無 |
| 進丹藥 | 好轉機率 +40% | 25% 加重；連續服用會中毒 |
| 罷朝靜養 | 好轉機率 +25%，勞損 −3 | 權閹與派系在你休養時更放肆 |
| 祈禳 | 龍顏 +5，好轉機率 +5% | 言官議論 |
| 西洋藥方 | 好轉機率 +35% | 需要曾經優禮西洋教士；清流不滿 |

- **病中的政治效應**
  - 病到「重」以上：皇叔與權閹的謀逆進度 +3／旬
  - 沒有皇子時，再 +3
  - 「紅丸」刺殺鏈只在皇帝生病時觸發（§4.6）

### 4.3 龍顏（心情）
- 數值 0–100，隱藏；頂欄的皇帝畫像有五種表情，對應五級描述：龍心大悅／心緒平和／悶悶不樂／鬱鬱寡歡／煩躁易怒
- 正面：捷報、祥瑞、朝貢、皇子誕生、消遣、妃嬪好感高
- 負面：兵敗、陷地、民變、言官切諫、勞損、後宮爭鬥、刺殺未遂
- 龍顏 < 15 時，每旬 20% 機率「天顏震怒」：隨機廷杖一位大臣，朝望 −3，該大臣的派系怨望 +8

### 4.4 外表與起居
- 起居畫面顯示：精力、勞損、病情、龍顏、本旬已用的消遣、狀態清單
- 每項都附「為什麼」：例如「勞損 3：上旬透支 2，前旬操勞 1」

### 4.5 消遣
- **規則**
  - 每旬只能選一種
  - 同一種消遣冷卻 3 旬
  - 6 旬內第二次選同一種，效果只剩 60%；第三次剩 30%
  - 冷卻與遞減分開計算：冷卻結束後仍可能在遞減期內

| 消遣 | 精力 | 成本 | 龍顏 | 其他效果 | 風險或賭性 |
|---|---|---|---|---|---|
| 遊幸西苑 | 1 | — | +8 | 勞損 −1 | — |
| 觀戲聽曲 | 1 | 內帑 2 萬 | +12 | — | 言官議論奢靡（10%，朝望 −1） |
| 臨池揮毫 | 1 | — | +6 | 勞損 −1；言路 +1（士林好感） | — |
| 臨幸後宮 | 1 | — | +10 | 選定的妃嬪好感與恩寵上升，其他妃嬪妒意上升；可能懷孕 | 見 §14 |
| 禮佛問道 | 1 | — | +6 | 病中好轉機率 +10% | 方士趁機獻丹（事件） |

### 4.6 宮廷護衛與刺殺
- **護衛等級**：1–5，由錦衣衛指揮使的能力與忠誠、京營提督的忠誠、「加強宿衛」詔書決定
- **刺殺嘗試的來源與觸發條件**

| 來源 | 觸發條件 |
|---|---|
| 權閹 | 危機感 ≥ 80，而且謀逆進度 ≥ 50 |
| 皇叔 | 分支為「覬覦」，而且皇帝無子或病重 |
| 某派系 | 該派怨望 ≥ 90 |
| 建州細作 | 建州敵意 ≥ 80，而且皇帝最近一年曾親征或出塞 |

- **成功率**：`基礎 40% − 護衛等級 × 8%`（微服時護衛視為 1）
- 失敗會觸發刺殺事件鏈（§13.6）；成功則以「駕崩」結局收場

## 5. 奏摺（被動）

### 5.1 上呈規則
- 每件事情都有**重要度**：1 例行、2 重要、3 大事
- 是否送到皇帝面前，由主管官員的授權決定

| 授權 | 重要度 1 | 重要度 2 | 重要度 3 |
|---|---|---|---|
| 事事奏請 | 上呈 | 上呈 | 上呈 |
| 常例自專（預設） | 自行處理 | 上呈 | 上呈 |
| 便宜行事 | 自行處理 | 自行處理 | 上呈 |

- 不上呈的事情由大臣處理，結果記入**處分錄**（§5.5）
- 以下奏摺不受授權影響，一律上呈：
  - 言官的彈章
  - 東廠密報
  - 飛報（地區陷落、大軍入寇、民變攻城）
  - 皇帝親自交辦事項的覆奏
- **目標份量**：標準難度、預設授權下，每旬上呈 3–5 份，其中 1–2 份需要裁決

### 5.2 奏摺的組成（沿用 MVP 的文書格式）
- 標題、具奏人、發出旬、送達旬（附「在途幾旬」）
- **票擬**：內閣寫的摘要＋建議，免費閱讀
  - 票擬由首輔撰寫；首輔的派系與私心決定略去哪些線索（MVP 的「票擬未載」機制）
- **全文**：細讀耗精力 1；票擬未提到的段落會標成「票擬未載」
- **據報數字**：以標籤列出（兵數、銀兩、災情），進入地方面板供比對
- **請示**：若需要裁決，列出 2–4 個選項，每個標明效果與勝算

### 5.3 硃批
- 准、駁、留中（不決定），不耗精力
- 「留中」超過期限，就依主管官員的傾向處理
- 可以附加「另有旨」：開啟擬旨面板，以這份奏摺為對象

### 5.4 奏摺種類
| 種類 | 來源 | 特性 |
|---|---|---|
| 題本 | 各部、督撫 | 正式、慢，最容易粉飾 |
| 塘報、飛報 | 前線 | 快，常誇大戰功或敵勢 |
| 彈章 | 言官 | 數量受言路影響；約半數是風聞 |
| 密揭 | 特許的親信（§7.6） | 可以繞過票擬；只有密揭者自己的偏見 |
| 東廠密報 | 東廠 | 奪回東廠後完全可靠 |
| 處分錄 | 內閣彙整 | 每旬一份，列出大臣自行處理的事 |
| 使臣覆命 | 外交 | 受使臣能力與立場影響 |

### 5.5 處分錄
- 每旬自動生成，免精力
- 每條一行：誰、處理了什麼、怎麼處理、依據哪種傾向
  - 例：「兵部尚書（主和）：察哈爾請市，准開張家口馬市」
- 每條旁邊有「駁回」按鈕：花精力 1 撤銷這個處分
  - 撤銷要在處分生效前送達才有用
  - 撤銷會讓該大臣不悅（忠誠 −，派系怨望 +2）
- 這就是「皇帝聽報後決定干預」的主要入口

## 6. 詔書（主動）

### 6.1 擬旨流程
1. 從底部詔書列選一類，或從地區、人物、部隊面板直接點「下旨」
2. 選對象（地區、人物、部隊、勢力）
3. 選內容與規模（例：徵兵 5,000／10,000）
4. 面板即時顯示：
   - 精力
   - 錢糧（一次性＋每旬持續）
   - 送達：幾旬後送到
   - 執行：送到後幾旬完成
   - 預計完成日期
   - 勝算（若有不確定性）
   - 封駁風險（首輔或太后可能反對）
   - 派系反應（哪派高興、哪派不滿）
5. 用璽 → 詔書出現在輿圖上：驛馬沿路線移動的虛線
6. 行程頁列出所有在途與執行中的詔書；在送達之前可以「追回」，精力 1

### 6.2 時間的兩段
- **送達**：京師到目的地的驛程旬數
  - 京師 0 旬，鄰近 1 旬，遠省 2–4 旬，雲貴 6 旬，境外依路線
  - 驛傳整飭可以縮短，裁驛會延長
- **執行**：抵達後要多久才完成（徵兵 3 旬、築城 6 旬……）
- 完成後的結果也要靠奏報送回京師，所以「完成」和「得知完成」是兩件事

### 6.3 詔書八類
| 類別 | 圖示 | 內容 |
|---|---|---|
| 軍務 | 虎符 | 徵兵、募精兵、調兵、出征、出塞、授方略、犒軍、點驗、築城、造船、購火器、整頓京營 |
| 人事 | 吏部印 | 任命、罷免、召見、拿問、抄家、起復、特簡、設授權、賜密揭 |
| 財計 | 算盤 | 加派、蠲免、賑濟、截漕、發內帑、礦稅、開海、清丈、裁驛、捐納、營建 |
| 外交 | 節杖 | 遣使、撫賞、互市、和親、結盟、離間、招撫、冊封、議和、宣戰、要求內附 |
| 密偵 | 東廠印 | 密查、監視、點驗、安插眼線、羅織 |
| 內廷 | 鳳印 | 晉封、廢立、立儲、加強宿衛、療疾、罷朝靜養、選秀 |
| 消遣 | 扇 | 見 §4.5 |
| 大計 | 玉璽 | 罪己詔、大赦、經筵、南遷、出奔、親征 |

- 完整的數值見**附錄 B 詔書總表**

### 6.4 封駁與懿旨
- **封駁**：違反「祖制」的詔書，首輔可能不擬旨
  - 例：加礦稅、開海、廢藩、內廷干政、賜死宗室
  - 機率 = 首輔的剛直度 × 30% ＋ 首輔派系反對度 × 30%
  - 被封駁時可以：
    - 收回
    - 強行頒下：朝望 −5，首輔派系怨望 +10
    - 改由中旨（司禮監）直接下：沒有封駁，但言官大譁，朝望 −8；中旨需要掌印太監配合
- **懿旨**：太后可以否決內廷詔書（廢后、立儲、處置宗室）
  - 太后好感 ≥ 60 時同意
  - 40–59 時會附條件，例如要求提拔外戚
  - < 40 時反對；強行頒下，太后好感 −20，朝望 −10

### 6.5 詔書的派系反應
- 每道詔書都帶有派系標籤，例如加派：閹黨 +、清流 −、齊楚浙 −
- 頒下時，相關派系的聲勢與怨望會變動；擬旨面板會預先顯示

### 6.6 同旬限制
- 同一對象、同一種詔書，一旬只能下一次（沿用 MVP v0.2.1）
- 詔書沒有總數上限，只受精力限制

### 6.7 罪己詔與大赦
| 詔書 | 效果 | 限制 |
|---|---|---|
| 罪己詔 | 朝望 +10，民心全國 +5；龍顏 −15 | 每局 2 次；第二次效果減半 |
| 大赦 | 民心 +8；監獄裡的冤獄平反；流寇招撫的勝算 +1 級 | 每 36 旬 1 次；吏治 +5（變壞） |

### 6.8 親征（大計，賭性）
- 精力 3；開拔銀 30 萬；皇帝隨京營或指定部隊出發
- 親征期間：
  - 前線的資訊完全準確，戰報即時
  - 方略卡由你親選；部隊士氣 +2 級
  - 京師變成黑箱：所有京師與朝中的奏摺延遲 1 旬，權閹與皇叔的謀逆進度 +5／旬
- 戰敗時有被俘的風險（勝算顯示），被俘即「亡國」，史書記為「北狩」

### 6.9 南遷與出奔（逃離京城）
| 項目 | 南遷 | 出奔 |
|---|---|---|
| 時機 | 任何時候；京師受威脅時太后與清流反對減弱 | 京師被圍，或城破前 1 旬 |
| 精力 | 3 | 0 |
| 籌劃時間 | 3 旬（期間京師民心 −10／旬） | 立即 |
| 帶走 | 國庫 70%、太倉 30%、內帑全部、京營 60% | 內帑 50%、京營 20% |
| 成功率 | 十拿九穩（除非籌劃期間京師被圍） | 依敵軍距離：凶多吉少到五五之數 |
| 朝望 | −25 | −35 |
| 之後 | 南直隸成為新京師；北方驛程 +2 旬；北方各地控制度 −20；北方勢力的敵意 +15 | 同南遷，另外失散大臣 30% |
| 結局 | 撐到 180 旬是「偏安」，否則依後續狀況 | 被擒即「亡國」 |

- 南遷後可以「還都」：收復京師並且駐軍 ≥ 5 萬，下詔書，籌劃 6 旬，朝望 +20

| 暗通 | 某勢力或無 | 隱藏 | 通敵 |
| 名望 | 0–100 | 五級描述 | 任免的派系反應 |
| 關係 | 同鄉、師生、姻親、仇怨 | 召見與東廠可以查出 | 彈劾與偏袒會循著關係 |

- **能力評語**：庸碌／平平／幹練／優長／卓絕
  - 吏部考語的偏差：± 1 級，吏治差時貪官會被說成「幹練」
  - 召見觀察：若皇帝的謀略加上對方的謀略較高，評語較準
  - 東廠查核：準確
- **個性標籤**（各有規則效果）

| 標籤 | 效果 |
|---|---|
| 剛直 | 封駁率 +；不受賄；被罷免時清流怨望 +5 |
| 圓滑 | 各派怨望變動減半；票擬傾向迎合皇帝 |

| 好名 | 喜歡上疏切諫；主戰傾向 + |
| 擁兵自重 | 野心成長加倍；會要求便宜行事 |
| 迂腐 | 治政 −1；凡事援引祖制 |
| 敢任事 | 便宜行事時效果 +20%，越權機率也 +20% |
| 怯戰 | 統兵評語通常虛高；方略常選固守 |
| 刻薄寡恩 | 部隊士氣 −1 級，但軍紀好 |

### 7.3 任免
| 操作 | 精力 | 時間 | 說明 |
|---|---|---|---|
| 任命 | 1 | 送達＋赴任（新官從原地出發） | 候選人：吏部會推 3 人＋皇帝可以特簡任何在冊官員 |
| 罷免 | 1 | 送達 | 職位由次官暫署，能力 −1 |
| 召見 | 2 | 在京：立即；外官：驛程進京 | 外官離任期間由次官暫署 |
| 拿問 | 1 | 錦衣衛送達 | 擁兵者可能抗命，顯示勝算 |
| 抄家 | 1 | 拿問後 1 旬 | 得銀，依操守與官位；派系怨望 +10 |
| 起復 | 1 | 送達 | 起用被罷或丁憂的官員 |
| 特簡（押寶用人） | 1 | 送達 | 起用資歷不足或有爭議的人：能力高的機率提高，但派系反彈；勝算顯示「此人可用」的把握 |

- **任命的派系反應**：新官所屬派系聲勢 +，被替換者的派系怨望 +（被罷免者名望越高，怨望越多）
- **人才池**：每局生成約 120 位官員，其中約 45 位在職；另有在野名士 10 位，可以起復

### 7.4 授權
- 適用職位：內閣、六部、督師、巡撫、總兵、出征主將
- 預設：常例自專
- 每旬最多變更 3 個職位，不耗精力；變更以詔書送達，遠地需要時間

| 授權 | 上呈份量 | 反應速度 | 傾向的影響 | 副作用 |
|---|---|---|---|---|
| 事事奏請 | 多（每項重要度 1 都上呈） | 慢：要等往返驛程 | 小 | 精力被淹沒；該大臣不悅（忠誠 −1／旬） |
| 常例自專 | 中 | 例行事務即時 | 中 | — |
| 便宜行事 | 少 | 快：連重要事項都即時處理 | 大：完全依傾向與私心 | 野心 +1／旬；高野心＋擁兵＋欠餉 → 自立為軍閥（§10.2） |

### 7.5 大臣自行處分的決策規則
- 每個可處分的事項有 2–4 個選項，每個選項帶標籤：戰／和、嚴／寬、派系利益、私利
- 大臣選分數最高的選項：

```
分數(選項) = 傾向契合 × 3
           + 本派利益 × 2
           + (1 − 操守) × 私利 × 4
           + 能力 × 合宜度
```

- 「合宜度」是選項對真實局勢的適當程度
- 能力越高的大臣，越看得清真實局勢，越容易選到合宜的選項
- 結果寫入處分錄；重要度 2 以上的事項，結果另外以奏報回報

### 7.6 密揭
- 皇帝可以「賜密揭」給最多 3 位官員（人事類詔書，精力 1）
- 密揭者可以繞過內閣直接上奏；奏報不經票擬，也不會被司禮監截留
- 密揭者的派系會因此得勢（聲勢 +3），其他派系怨望 +2
- 密揭也有偏見：密揭者會告發政敵

### 7.7 人物卡（UI）
- 肖像（表情依忠誠與當下處境變化）、姓名、官職、籍貫、年齡
- 能力評語（附來源與日期）、傾向、派系、個性
- 履歷：最近 10 件行為紀錄（准過的請示、處分、戰績、被彈劾）
- 朕意：信任／存疑／不信（玩家自己標記）
- 動作：召見、任免、授權、拿問、密查、賜密揭

- 東廠羅織：打擊任何一派，可能曝光（§12.3）

## 9. 前朝勢力事件鏈

### 9.1 剷除權閹（開局主線，必出）

  - 危機感 0–100：皇帝每做一件不利於權閹的事 +5 到 +20

| 路線 | 步驟 | 代價 | 勝算的關鍵 |

  - 抄家得銀 150–300 萬兩
  - 東廠回到皇帝手中

### 11.3 據報兵數與實兵數
- **吃空餉**
  - 實兵 = 名冊兵數 × 實額率
  - 實額率 = 0.6 + 主將操守 × 0.3 + (欠餉 0 個月 ? 0.1 : 0)，上限 1
- **據報**
  - 各地每 3 旬由主將或巡撫上報一次兵數
  - 報的是名冊兵數，不是實兵數；主將的忠誠低時，還會再灌水 10–30%
- **點驗**：監軍或東廠點驗，可以得到實兵數
  - 點驗後該部隊的實額率改善 +0.1（嚇阻效果）
  - 主將忠誠 −5
- **輿圖「兵力」圖層**：每格標出
  - 「報：約三萬」
  - 來源（薊鎮總兵）
  - 幾旬前的消息（越舊字越淡）
  - 點驗過的以朱筆標出「點驗：二萬一千」
- **敵情**：敵軍人數只能來自邊報、戰報、使臣、降人、東廠；同樣標出來源與日期

### 11.6 交戰流程
1. **觸發**：敵我部隊在同一格，而且至少一方要戰（進剿、入寇、圍城）
2. **方略卡**：雙方各選一張
   - 我方：主將依傾向與能力選；若主將的授權是「事事奏請」或皇帝已授方略，就用皇帝的
   - 敵方：依 AI 與兵種選，隱藏
3. **勝算**：依據報的敵情計算，顯示五級並註明「據 XX 戰報」
4. **三階段結算**：接戰 → 鏖戰 → 決勝
5. **結果**：大捷／小勝／相持／小挫／大潰；傷亡、主將下落、敵軍退向
6. **戰報**：結果以塘報送回京師（有延遲），送達時播放戰鬥動畫（§18.6）

- **方略卡**（我方 7 張，敵方共用部分卡）

| 方略 | 適用 | 剋 | 被剋 | 效果 |
|---|---|---|---|---|
| 列陣決戰 | 兵多、戰力高 | 誘敵 | 夜襲 | 鏖戰階段 ×1.2 |
| 堅壁固守 | 守城、等援軍 | 列陣、夜襲 | 斷糧 | 我方傷亡 −40%，敵 −20%；拖延 1 旬 |
| 夜襲 | 主將謀略 ≥ 3 | 列陣 | 固守 | 接戰階段 ×1.5；失敗時我方士氣 −1 級 |
| 誘敵伏擊 | 山地、主將謀略 ≥ 4 | 騎兵衝陣 | 列陣、斥候 | 成功時決勝 ×2 |
| 斷其糧道 | 敵軍深入或境外 | 固守 | 速戰 | 不立即決戰；敵每旬士氣 −1 級，持續 3 旬 |
| 孤注一擲 | 任何時候 | — | — | 全部階段 ×1.6，但結果只會是「大捷」或「大潰」；主將陣亡機率 ×3 |
| 招降 | 對流寇、土司、軍閥 | — | — | 不交戰；依對方士氣與我方實力判定，成功則招撫（附詐降風險） |

- **三階段**（每階段雙方各損失兵力）

```
階段戰力 = Σ(兵數 × 兵種戰力) × 士氣倍率 × 主將統兵倍率 × 地形 × 方略倍率 × 隨機(0.85–1.15)
士氣倍率：五級 1.2 / 1.0 / 0.85 / 0.7 / 0.5
統兵倍率：1–5 → 0.8 / 0.9 / 1.0 / 1.15 / 1.3
每階段損失 = 對方階段戰力 × 階段係數（接戰 0.05、鏖戰 0.10、決勝 0.15）÷ 我方總戰力 × 我方兵數
士氣：每階段若損失 > 對方，士氣 −1 級；降到「潰散在即」時下一階段直接潰敗（損失 ×2）
```

- **結果判定**（決勝後）
  - 依雙方剩餘戰力比
  - ≥ 2 大捷；1.2–2 小勝；0.83–1.2 相持；0.5–0.83 小挫；< 0.5 大潰
- **主將下落**：大潰時 20% 陣亡、10% 被俘、5% 降敵（忠誠低時 ×3）

| 東廠 | 京中 1 旬；地方往返驛程 | **奪回後絕對可靠** | 權閹控制時：會過濾、羅織 |

### 12.2 據報規則（沿用 MVP）
- 每個數字都附來源與觀察日期
- 同一事項 3 旬內出現矛盾的說法，標示「說法不一」
- 戶部帳目晚 1 旬；各省錢糧每 3 旬一期
- 地方面板依時間排列各來源的說法，方便比對

### 12.3 東廠
- **兩個階段**

| 階段 | 條件 | 密報 |
|---|---|---|
| 權閹掌控 | 開局 | 涉及閹黨的事一律說好話；涉及清流的事 50% 夾帶捏造的罪名；其他事項準確 |
| 天子親掌 | 換上自己人當提督 | **100% 正確**，標上「東廠・確」的朱印 |

- **奪回東廠的方法**
  - 罷免提督並任命新人：朝望 ≥ 50，或太后懿旨，或閹黨聲勢 < 30%
  - 雷霆一擊順帶奪回
- **密偵行動**

| 行動 | 精力 | 成本 | 時間 | 結果 |
|---|---|---|---|---|
| 密查某地 | 1 | 2 萬 | 京師 1 旬；地方往返驛程 | 真實民心、錢糧截留、災情、實兵 |
| 密查某人 | 1 | 2 萬 | 同上 | 真實能力、操守、派系、暗通 |
| 監視 | 1＋每旬 1 萬 | — | 持續 | 每旬一份某人的行蹤報告 |
| 點驗軍伍 | 1 | 1 萬 | 同上 | 實兵數 |
| 安插眼線 | 1 | 5 萬 | 3 旬布置 | 某勢力或某王府的動向，每 3 旬一報 |
| 羅織 | 1 | 5 萬 | 2 旬 | 捏造某人的罪證，讓拿問「師出有名」；目標派系怨望 +15 |

- **曝光機率**（每次行動判定一次）

```
曝光率 = 10%
       + 目標位階加成（巡撫級 +5、尚書級 +15、內閣或宗室 +25、太后或後宮 +30）
       + 目標所屬派系聲勢 ÷ 4
       + 9 旬內查同一目標的次數 × 10%
       − 提督謀略 × 4%
（羅織的曝光率 ×1.5）
```

- **曝光的後果**（依目標位階分四級）

| 級 | 目標 | 後果 |
|---|---|---|
| 一 | 地方官、將領 | 朝望 −3；目標忠誠 −20 |
| 二 | 尚書、督師 | 朝望 −6；目標派系怨望 +15；言官彈劾「廠衛橫行」3 份 |
| 三 | 內閣、宗室 | 朝望 −12；所有派系怨望 +8；言路 −10；狀態「廠衛之禍」（9 旬：所有官員忠誠 −1／旬） |
| 四 | 太后、後宮；或羅織被揭穿 | 朝望 −20；太后好感 −30；清流伏闕；提督必須交出抵罪，否則朝望再 −10 |

### 12.4 勝算（五級，不顯示數值）
| 勝算 | 機率區間 | 圖示 |
|---|---|---|
| 十拿九穩 | ≥ 90% | 五枚銅錢 |
| 勝算頗高 | 70–89% | 四枚 |
| 五五之數 | 40–69% | 三枚 |

  - 有東廠確報時，標示「依東廠確報」，勝算正確

### 13.4 兩難的設計準則
- 每個選項至少讓兩方受損（例：派系、民心、國庫、太后、龍顏）
- 不能有任何選項在所有面向都最好
- 至少一個「拖延」選項：短期沒有代價，但演化到下一階段時代價更大
- 選項文字寫明可見的代價；隱藏的代價（依分支而異）留到結果揭露
- **兩難範例**（共 20 組，見附錄 C；以下節錄 6 組）

| 事件 | 選項 A | 選項 B | 選項 C |
|---|---|---|---|
| 陝西大旱，請蠲免 | 蠲免：民心 +，國庫 −8／旬（6 旬） | 加派遼餉照徵：國庫 +，陝西民變機率大增 | 截漕賑濟：民心 +，太倉 −30 萬石 |
| 遼東請餉，國庫只夠發一半 | 先發遼東：遼東士氣穩，其他三鎮欠餉 | 平分四鎮：各鎮都不滿 | 動用內帑：內帑 −40 萬，龍顏 − |
| 清流彈劾功臣督師 | 拿問：清流 +，前線換將 | 留中：清流怨望 + | 申飭言官：言路 − |
| 海商請招撫，要求「海防都督」 | 准：得水師，他坐大 | 只給遊擊：他可能拒絕 | 剿：要水師，勝算低 |

### 13.5 賭性選項的規範

### 15.2 稅收漏斗（沿用 MVP `collectionRate`）
```
實收 = 應收
     × 稅則倍率（寬 0.85 / 常 1.0 / 加派 1.2）
     × (1 − 吏治 ÷ 250)
     × (1 − max(0, 民心不滿 − 40) ÷ 100)
     × (0.85 + 朝望 ÷ 670)
     × 災荒倍率 × 控制度 ÷ 100
     × 地方官截留（操守 < 0.5 時減 0–25%）
```

## 17. 難度與平衡

### 17.1 目標（標準難度，模擬 300 局）
| 策略 | 說明 | 5 年存活率 | 中興率 |
|---|---|---|---|
| 無為 | 什麼都不做，全部依大臣處分 | 0% | 0% |
| 亂按 | 隨機選選項、隨機下詔書到精力用完 | ≤ 10% | 0% |
| 照票擬 | 所有上呈事項依票擬；不主動下詔 | 25–35% | ≤ 2% |
| 全授權 | 所有職位便宜行事 | 15–25% | ≤ 2%（軍閥自立頻繁） |
| 模擬玩家 | 依已知資訊的規則：先奪東廠、點驗、平衡派系、及時賑濟與調兵 | 60–70% | 15–25% |
| 全知 | 看得到真相 | ≥ 90% | 45–60% |

### 17.2 確保「亂按會死」的機制
- 結構性赤字（§15.3）：不開源就會破產
- 三個計時器：國庫約 15 旬見底、邊餉約 10 旬到兵變線、權閹謀逆約 30–45 旬發動
- 勢力 AI 會利用朝廷的困境：欠餉、陷地、民變都會讓入寇的機率上升
- 每個詔書都有代價：隨機拿問會累積怨望；隨機加派會激起民變；隨機出塞會被殲滅
- 精力透支：亂按的玩家會累積勞損而生病

### 17.3 自動模擬規格（沿用 MVP `scripts/sim.ts` 的思路）
- 每種策略跑 N 局，輸出：存活率、各結局比例、平均分數、平均存活旬數、死因分布、各事件鏈的分支得分、每旬上呈份數與精力使用
- 驗收條件
  - 執行錯誤 0
  - 存活率落在 §17.1 的範圍
  - 每旬平均上呈 3–5 份
  - 模擬玩家每旬平均精力花費 4–6（略高於回復，迫使玩家取捨）

## 19. 移植與資料規格

### 19.1 架構原則
- **模擬核心與表現層分離**：核心是純邏輯，不碰畫面；可以用任何語言實作
- **真相層與認知層分離**：表現層只能讀取 `playerView(state)` 產生的資料，拿不到任何隱藏欄位（分支、操守、忠誠、野心、真實兵數……）。這是防止作弊與保證「據報」玩法的關鍵（沿用 MVP `src/core/view.ts`）
- **內容資料化**：地區、勢力、兵種、職位、詔書、事件鏈、文本樣板放在資料檔；只有複雜的事件鏈邏輯才寫成程式掛勾
- **決定論**：所有隨機都經過狀態內的 RNG；同一種子＋同一串操作，結果完全相同

### 19.2 主要資料結構（與語言無關）
- 以下用「欄位：型別 — 說明」表示；★ 表示隱藏欄位，不得出現在 playerView

**GameState**
- version：整數
- seed：字串；rng：RNG 狀態
- turn：整數；maxTurn：180
- difficulty：easy／normal／hard；perk：天賦 ID
- emperor：Emperor
- world：World
- chars：Character 的對照表
- factions：Faction 的對照表
- armies：Army 陣列
- chains：ChainState 陣列
- docs：Doc 陣列；orders：Edict 陣列
- statuses：Status 陣列
- player：玩家的標記（朕意、心證、註記、授權設定）
- log、stats；over：結局或空

**Emperor**
- energy：整數（−3～10）；energyMax：整數；fatigue：0–10
- mood★：0–100
- illness：{種類, 嚴重度, 起始旬, 治療加成} 或空
- leisureLast：{消遣 ID: 最近旬數}；leisureCount：{消遣 ID: 6 旬內次數}
- guard：1–5
- heirs：皇子女陣列；heirDesignate：皇子 ID 或空

**World**
- treasury★、grain、privy：數字（國庫的真值是隱藏的，玩家看到的是 reportedTreasury）
- prestige★、speech★（言路）、corruption★：0–100（玩家只看到五級描述）
- borderArrears：月數
- taxPolicy：寬／常／加派
- regions：Region 的對照表
- mods：開源節流的持續效果（礦稅、開海、加派、裁驛……）與到期旬
- ledger、flows：帳冊（沿用 MVP）
- capital：京師或南直隸
- dongchang：權閹或天子

**Region**
- id、名稱、類型（京畿、邊鎮、行省、境外）
- owner：勢力 ID；control★：0–100
- unrest★：0–100；sect★：0–100（教門）
- disaster：{種類, 嚴重度, 到期} 或空
- garrisonRoll：名冊兵數；garrisonReal★：實兵數
- 驛程、鄰接、應收稅額、漕糧、兵源（可募兵種）
- reports：據報紀錄陣列 {欄位, 值, 來源, 觀察旬, 送達旬}

**Character**
- id、姓名、肖像種子、年齡、籍貫
- kind：文官、武將、太監、宗室、妃嬪、外藩首領、土司
- post：職位 ID 或空；authority：事事奏請／常例自專／便宜行事
- abilities★：{統兵, 治政, 理財, 謀略}（各 1–5）
- warPeace：主戰／持重／主和；severity：嚴刻／中道／寬仁；traits：個性標籤
- faction：派系 ID 或無黨；secretFaction★：暗附的派系
- integrity★、loyalty★、ambition★：數值；collusion★：暗通的勢力
- fame：名望；ties：關係陣列 {對象, 類型}
- record：行為紀錄陣列
- consort：妃嬪專屬欄位 {位分, 家世, 性情, 好感★, 恩寵, 妒意★, 野心★, 子嗣}

**Faction**（同時用於朝中派系與地圖勢力，以 kind 區分）
- id、名稱、顏色、旗號
- kind：court（朝中派系）或 power（地圖勢力）
- court 專屬：seats、clout（聲勢）、grievance★（怨望）
- power 專屬：strength★、wealth★、attitude★、ambition★、personality、relations★（對其他勢力）、standing（地位）、regions
- reportedStrength、reportedAttitude：據報值與來源

**Army**
- id、名號、owner：勢力 ID
- commander：人物 ID
- units★：[{兵種, 實兵數}]；rollSize：名冊兵數；reportedSize：據報兵數與來源
- morale★、supply★、training
- region；path：路線；eta：抵達旬
- mission；stratagem：預定方略

**Edict（詔書）**
- id、類型 ID、對象、參數
- energy、cost：{國庫, 太倉, 內帑, 每旬持續}
- issuedTurn、arriveTurn、completeTurn
- status：在途／執行中／完成／被追回／被封駁
- odds：勝算等級與依據；factionReaction

**Doc（奏摺）**
- 沿用 MVP `Doc`：id、種類、來源、地區、主題、發出旬、送達旬、標題、段落（含白話、票擬縮寫、線索標籤）、摘要、建議、據報數字、請示
- 新增：importance（1–3）、chainId、delegatedBy（處分錄用）、certified（東廠確報）

**ChainState（事件鏈）**
- uid、定義 ID、地點、branch★、stage★、startTurn
- actors：角色對照表；data★、flags★
- playerJudgement：玩家的判斷
- resolved：{旬, 結果, 得分} 或空

**Status（狀態）**
- id、名稱、圖示、來源、剩餘旬數、效果陣列

### 19.3 決定論與存檔
- RNG：32 位元的可序列化 PRNG（MVP 使用 mulberry32 類），狀態存在 GameState 內
- 不可以使用系統時間、雜湊表的迭代順序或浮點運算中與平台相關的函式來影響模擬結果
- 存檔 = 整個 GameState 序列化為 JSON，加上版本號；讀檔時依版本號做資料遷移
- 驗證：同一種子＋同一串操作，在不同平台上的最終 GameState 雜湊必須相同（作為移植的驗收測試）

### 19.4 內容資料檔
| 檔案 | 格式 | 主要欄位 |
|---|---|---|
| regions | CSV | id、名稱、類型、驛程（日）、鄰接、應收稅、漕糧、預設駐軍、兵源、經緯度（首府） |
| factions | JSON | id、名稱、kind、顏色、旗號、開局數值、AI 傾向權重、開局關係 |
| unit_types | CSV | id、名稱、戰力、特長（地形、守城、海戰）、餉、來源地、每次上限 |
| posts | CSV | id、名稱、層級、席位點數、職掌（可處分的事項類型）、預設授權 |
| edicts | JSON | id、類別、精力、成本公式、送達規則、執行旬數、條件、效果、勝算公式、派系標籤、封駁規則 |
| stratagems | JSON | id、名稱、條件、各階段倍率、剋制關係 |
| chains/*.json | JSON | §13.1 的欄位；條件與效果用下方的小型 DSL；必要時引用程式掛勾名稱 |
| statuses | JSON | id、名稱、圖示、預設旬數、效果 |
| leisure | JSON | id、精力、成本、龍顏、副作用、風險 |
| texts/*.json | JSON | 文書樣板，以 `{地名}`、`{人名}`、`{數字}` 等佔位；每個樣板有白話版本與詞彙標記 |
| glossary | CSV | 詞、註解（沿用 MVP 約 105 條） |

- **條件與效果的 DSL**（JSON）
  - 條件：`{"all": [{">=": ["faction.yandang.grievance", 70]}, {"==": ["chain.eunuch.branch", "plot"]}]}`
  - 效果：`[{"add": ["world.prestige", -5]}, {"status": ["士林寒心", 12]}, {"spawnArmy": {"faction": "chuang", "region": "shaanxi", "size": 3000}}]`
  - 支援的運算：all、any、not、==、!=、>、>=、<、<=、chance（機率）；效果：add、set、status、spawnArmy、moveArmy、post（產生文書）、hook（呼叫程式掛勾）

### 附錄 E：文本樣板範例
- 樣板以佔位符表示變數；每段附白話；線索段落標記對哪個分支不利

**塘報（誇大型）**
- 原文：「{日期}，虜騎{報敵數}犯{地名}。臣督將士奮擊，斬首{報斬首}級，奪馬{數}匹，虜遁出塞。我軍傷亡{報傷亡}人。」
- 白話：「{日期}，敵騎約{報敵數}人進犯{地名}。我率軍迎擊，殺敵{報斬首}人，敵人退出邊外。我軍傷亡{報傷亡}人。」
- 真相欄位：真實敵數、真實斬首（報斬首 ÷ 1.5–3）、真實傷亡（報傷亡 × 1.5–2），寫入謊言簿

**東廠確報**
- 原文：「〔確〕{地名}實兵{實兵數}，名冊{名冊數}，空額{差額}。{將領}歲侵餉銀約{數}萬兩。」
- 白話：「〔確〕{地名}實際只有{實兵數}人，名冊上卻寫{名冊數}人，空了{差額}人。{將領}每年侵吞約{數}萬兩軍餉。」

**處分錄條目**
- 「{官職}{姓名}（{傾向}）：{事項}，{處分}。」
- 例：「兵部尚書某（主和）：察哈爾請市，准開張家口馬市。」

**兩難事件（陝西大旱）**
- 標題：「陝西撫臣奏：赤地千里，請蠲本年錢糧」
- 選項 A「准蠲免」：說明「陝西 6 旬內不繳錢糧（國庫每旬 −2），民心回升」；狀態「皇恩浩蕩」6 旬
- 選項 B「遼餉照徵」：說明「國庫照收；陝西民變的機率大增」；狀態「民怨沸騰」6 旬
- 選項 C「截漕賑濟」：說明「太倉 −30 萬石；民心回升；但漕糧被截，京師米價上漲」
- 隱藏：若分支是「巡撫貪墨」，A 與 C 的錢糧有一半被侵吞
